# 金币小镇 · 3D

用现代浏览器打开本文件夹中的 `index.html`。请保留同目录的 JS、CSS 和 vendor 文件夹；无需联网，无需安装依赖。

- 拖动小镇旋转视角，鼠标滚轮或双指缩放；右上角也有缩放与复位按钮。
- 点击建筑或右侧模型缩略图选择建筑，点击「建造 / 升级」消费金币。
- 已建造建筑可以点击「进入」。七座建筑都有独立的低分辨率室内场景、主题色和经营按钮，状态与收益会跟随本地存档保存。
- 点击「展示全部模型」，可比较四个外观阶段：1–2级、3–5级、6–7级、8级以上，共 28 个建筑外观。此模式不会购买建筑，也不会改变收益。
- 四个阶段会改变主体结构、首层入口、占地轮廓和功能附属区。升级到 3、6、8 级时，建筑与周边地块会同时进化；8 级之后保持第四阶段外观，继续升级仍可提高收益。
- 七类建筑沿不同方向扩张：农场逐步占用更多田地并增加温室、粮仓和农作物；咖啡馆保持紧凑，占地小幅增长，重点增加玻璃茶屋、精细露台与装饰；矿场沿地面铺开轨道、矿车、吊架、碎石场和冶炼烟囱。小屋先从一户增加到两户，随后翻新屋顶、门窗和庭院；面包坊先从单炉增加到双炉，随后改善炉体、店面与展示区。银行扩建为翡翠色石柱金融馆，灯塔延伸出码头与多座航标塔。
- 七栋建筑有各自的主色：住区砖红、咖啡馆淡紫、农场红棕与麦绿、矿场冷灰与锈色、面包坊橙陶、银行翡翠绿、灯塔珊瑚红与海蓝。金币色只用于小面积的点缀。
- 总资产、升级价格与收益使用完整数字显示。每轮产出自动按 100000、10000、1000、100、10、1 拆分；例如 123456 = 100000×1 + 10000×2 + 1000×3 + 100×4 + 10×5 + 1×6。
- 建筑上方显示各面值金币及数量，下方「本次产出」显示合计组合。动画不重复增加金币；不足 1 枚的生产进度会保存到下一次结算。
- 金币自动产生；「收集金币」额外增加 1 枚铜币。点击币种试听金属落地声。
- 自动读取旧版 `coinTownSave` 本地存档。离线收益上限 8 小时；关闭页面前自动保存。
- 桌面与横屏采用 16:9，手机竖屏采用可滚动布局。
- 界面和三维场景采用参考图校准的夜间像素经营风格：深青黑环境、暖橙灯光、硬边阴影、低分辨率颗粒和密集的箱庭细节。主窗口固定为 16:9，窄屏会切换为可滚动布局。
- 小镇地面由独立草地与道路方格组成，未建造地块显示围栏、木箱和施工告示。建筑的庭院、田地、轨道、货摊或码头与主体模型一起占地，升级后会向周围土地扩展。
- 道路上有像素居民持续行走，路口设置灯柱、树木和花朵；灯柱带有暖色点光源，夜景中会在地面留下局部光晕。
- 右侧建筑栏使用半透明像素化建筑图作为每张卡片的背景，背景会跟随建筑当前的四段外观阶段更新；卡片之间只保留细线和色彩边缘，减少分割感。
- 小镇采用动态日照系统：游戏内一天为 12 分钟，对应 24 小时。太阳、天空光、雾色和路灯会随时间经过黎明、白天、黄昏和夜晚，顶部时钟显示当前小镇时间。

## 建筑玩法扩展

`building-runtime.js` 是建筑内部玩法的统一入口。小屋可以邀请住户、布置家具和收租；咖啡馆可以研发饮品、营业和接待客人；农场可以切换作物、播种并等待收获；矿洞可以勘探矿层、派矿车并精炼矿石；面包坊可以学习配方、等待烤炉出炉并陈列面包；金库可以扩建、增加保险箱和结算利息；灯塔可以点亮信标、发现航线和迎接商船。部分动作会消耗金币或等待生产时间，收益会拆分成金币组合并在小镇中显示。接口说明与示例见 `BUILDING_API.md`。

`interior-models.js` 为七座建筑提供独立的 3D 室内模型。每个房间都有不同的墙面、地面、门窗、灯具和功能家具，并按建筑的四个外观阶段增加设施。进入建筑后，室内画布支持拖动旋转、滚轮缩放和触摸拖动；模型中的家具节点带有 `userData.interiorPart`，可供后续点击设施、任务和镜头聚焦功能接入。

## 独立模型

`models/` 内每栋建筑都有四份 OBJ 和同名 MTL 材质文件，命名为 `hut-lv1.obj` 至 `hut-lv4.obj` 等，共 28 个阶段模型，可一起导入 Blender 等三维工具。它们由游戏使用的同一组网格模型导出，坐标轴 Y 向上。`manifest.json` 记录每份模型的名称、等级区间和占地尺寸；不带 lv 的文件为基础外观。

`building-stages.png` 是 28 个外观的总览图，每行是一种建筑，从左到右为四个等级区间。

| 文件 | 建筑 | 结构 |
| --- | --- | --- |
| hut.obj | 叮当小屋 | 单户到双户，后期升级为精装修花园住区 |
| cafe.obj | 月桂咖啡馆 | 淡紫屋顶、玻璃茶屋、精巧露台 |
| farm.obj | 金穗农场 | 红棕谷仓、成片农田、温室、筒仓 |
| mine.obj | 琥珀矿洞 | 冷灰矿坑、轨道、吊架、冶炼烟囱 |
| bakery.obj | 云朵面包坊 | 单炉到双炉，后期升级炉体与精品店面 |
| bank.obj | 翡翠金库 | 翡翠屋顶、石柱大厅、金融广场 |
| tower.obj | 月光灯塔 | 珊瑚红塔身、海蓝码头、双港航标 |
